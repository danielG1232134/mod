# LoudWake — установка только с iPhone

1. Открой репозиторий `danielG1232134/mod` на GitHub.
2. Нажми **Settings**.
3. Открой **Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Branch: **main**.
6. Folder: **/(root)**.
7. Нажми **Save**.
8. После публикации открой адрес GitHub Pages и допиши `/loudwake/`.
9. Открой эту страницу именно в Safari.
10. Нажми **Поделиться → На экран «Домой» → Добавить**.

## Что работает
- выбор времени;
- PIN;
- графический ключ;
- фото-задание через камеру;
- тест звука;
- сохранение настроек на iPhone;
- запуск испытания вручную;
- если LoudWake открыт, он может сработать в выбранное время.

## Ограничение iPhone
Веб-приложение не может гарантированно запустить звук, если оно полностью закрыто или iPhone заблокирован. Для гарантированного пробуждения поставь обычный будильник в приложении «Часы» на то же время. LoudWake используется как дополнительное испытание после пробуждения.
